# 3D models

## NASA 3D Resources
From NASA 3D Resources (https://github.com/nasa/NASA-3D-Resources), NASA media, not copyrighted in the US.
NASA's media guidelines apply: https://www.nasa.gov/nasa-brand-center/images-and-media/

- `lander.glb`: Apollo Lunar Module
- `rover.glb`: Mars 2020 Perseverance Rover (stand-in for a lunar rover)
- `lro.glb`: Lunar Reconnaissance Orbiter (A)

## Sketchfab, CC Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/)
Used unmodified apart from hiding a display floor and scaling to real size in the app.

- `vikram.glb`: "ISRO Chandrayyan-3 Mission Lander Module Vikram" by akareactor,
  https://sketchfab.com/3d-models/isro-chandrayyan-3-mission-lander-module-vikram-27e8d9b94f324e6b9a25b58e64317213
- `pragyan.glb`: "Pragyan Rover" by Core.anim8, https://sketchfab.com/3d-models/pragyan-rover-ecd749574f7343b6a6b39a4a9a02639d
- `yutu.glb`: "Yutu" by tashtego, https://sketchfab.com/3d-models/yutu-d9564c9a60c14b85a880cc0bfcf1a6b5
- `starship.glb`: "SpaceX Starship" by MartianDays, https://sketchfab.com/3d-models/spacex-starship-a8a0b69f776841a1a465cd9fb3762fd2
  (shown as Starship HLS)

`../draco/`: Draco mesh decoder from three.js (MIT), so the compressed models load offline.
